# 📋 TaskMaster - Modern Task & Accomplishment Tracker

A beautiful, modern single-page React application for managing and visualizing your daily, weekly, and monthly tasks with dark mode support and print capabilities.

![TaskMaster Screenshot](screenshot.png)

## ✨ Features

- ✅ **Task Management** - Add, edit, delete, and mark tasks as complete
- 📅 **Multiple Views** - Filter tasks by day, week, or month
- 📊 **Analytics Dashboard** - Visualize your productivity with native canvas charts
- 🌓 **Dark/Light Mode** - Beautiful themes with persistent preference
- 🖨️ **Print Support** - Print your tasks and charts with optimized formatting
- 💾 **Local Storage** - All data stored locally in your browser
- ⚡ **Fast & Lightweight** - No external dependencies, pure React
- 🎨 **Modern UI** - Clean, responsive design with smooth animations
- ⌨️ **Keyboard Shortcuts** - `Ctrl+P` to print, `Ctrl+K` to focus input

## 🚀 Quick Start

### Prerequisites

- Node.js 16+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/tasklist-app.git

# Navigate to project directory
cd tasklist-app

# Install dependencies
npm install

# Start development server
npm run dev
