## ▍$ cat pitch.txt

A beautiful, single-page React app for owning your daily, weekly, and monthly
tasks — with an analytics dashboard that renders its charts on **native canvas**
(no chart library shipped), dark/light themes that persist, print-optimized
output, and keyboard-first ergonomics. All state lives in the browser: no
account, no backend, nothing to configure.

```yaml
views     : day · week · month lenses over the same task set
analytics : native-canvas charts — completion curves + volume
themes    : dark / light with persisted preference
print     : optimized hard-copy of tasks + charts
data      : localstorage — private by default
```

## ▍$ ls features/

▸ full task crud — add · edit · delete · complete
▸ **three time lenses** — day, week, month filtering
▸ productivity dashboard — canvas-rendered charts, zero chart deps
▸ persistent dark / light mode
▸ print support with dedicated print stylesheet
▸ localStorage persistence — close the tab, keep the data
▸ responsive + animated, tight modern ui
▸ keyboard shortcuts throughout
